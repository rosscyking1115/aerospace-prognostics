# Repository Launch Strategy

> [!WARNING]
> Quarantined historical document. This is not the active roadmap.

This file is retained to explain the earlier productization drift. Do not use it
to plan a launch campaign, hosted service, or product work. The project is now
framed as an ML-engineer/MLOps portfolio reference implementation.

## Frozen Decision

- The working API, Streamlit console, Docker, evidence, SBOM, provenance, drift,
  and CI paths stay because they are the portfolio differentiator.
- The product-launch track is stopped.
- C-MAPSS remains an intentionally common benchmark. The model is not the main
  differentiator; the MLOps envelope is.
- Public-facing work should improve reviewer clarity, reproducibility, and
  evidence inspection.

## What Survives From The Old Strategy

The useful parts are still valid as portfolio evidence:

- crisp first-run path;
- readable README;
- screenshots and architecture diagram;
- benchmark limitations;
- API and container smoke evidence;
- release bundle, SBOM, provenance, and model-card links.

The obsolete parts are any instructions that imply a product launch, commercial
positioning, or broader hosted service roadmap.
